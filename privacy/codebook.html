二次元コード帳
プライバシーポリシー

catscatsnekoneko（以下「開発者」）は、Androidアプリ「二次元コード帳（2D Code Book）」における利用者の情報の取り扱いについて、以下のとおり定めます。

対象

本ポリシーは、Androidアプリ「二次元コード帳（2D Code Book）」のみに適用されます。

情報の取り扱いはアプリによって異なるため、アプリごとに別のポリシーを定めています。ほかのアプリについてはプライバシーポリシーの一覧をご覧ください。

端末内にのみ保存される情報

利用者が登録した内容は、すべて端末内のアプリ専用領域にのみ保存されます。

  • 読み取った二次元コードの模様（白黒のマス目）
  • 名前、タグ、利用者が自分で定義した項目とその値、備考
  • アイテムに添えた画像
  • セット（アイテムのまとまり）、お気に入り、絞り込みの条件
  • 自動入力のために利用者が登録した言葉と、指定した領域の見え方

これらが端末の外へ送信されることはありません。開発者がこれらの内容を見ることはできません。

Googleドライブへの自動バックアップの対象からも除外しています。そのため、機種変更時にこれらの内容が自動で引き継がれることはありません。

二次元コードの内容について

本アプリは、二次元コードの模様そのものを保存します。コードに書かれている内容（文字やデータ）を取り出して保存することはありません。

重複を判定するために内容のハッシュ値を保存していますが、ハッシュ値から元の内容を復元することはできません。

広告について

本アプリは広告を表示します。広告の配信には Google の AdMob を使用しています。

AdMob は、広告の配信と効果の測定のために、広告ID（リセット可能な識別子）、端末の情報、おおよその位置（IPアドレスに基づくもの）などを収集する場合があります。これらは Google によって収集されるものであり、開発者が個別に取得・保管するものではありません。

  • Google のプライバシーポリシー: policies.google.com/privacy
  • Google が広告で使用する情報について: policies.google.com/technologies/partner-sites

登録した二次元コードの模様・画像・入力した内容が広告のために使われることはありません。これらは端末の外へ送信されないためです。

広告に関する同意

欧州経済領域、英国、スイスからご利用の場合、初回起動時に Google のユーザーメッセージングプラットフォーム（UMP）を通じて同意を確認します。同意の内容は、アプリの設定画面からいつでも変更できます。

広告を表示しない画面

二次元コードを画面に表示している間と、コードを読み取っている間は、広告を一切表示しません。また、全画面広告（インタースティシャル広告）およびリワード広告は使用していません。

カメラの使用

カメラは、次の目的にのみ使用します。

  • 二次元コードの読み取り
  • アイテムに添える画像の撮影
  • 自動入力のための撮影

撮影した画像が端末の外へ送信されることはありません。

写真から文字を読み取る処理には、端末内で動作するモデルを使用しています。この処理のために画像がインターネットへ送信されることはありません。

バックアップファイル

設定画面から、登録内容をパスワードで暗号化した1つのファイルとして書き出せます。

  • 保存先は、利用者が端末のファイル選択画面で指定した場所です
  • 書き出したあと、アプリはそのファイルに一切関与しません。送信も参照もしません
  • ファイルの管理は利用者の責任で行ってください
  • パスワードを忘れると復元できません。開発者が復元することもできません

アプリが使用する権限

カメラ

上記「カメラの使用」のとおりです。許可しない場合、読み取りと撮影はできませんが、登録済みの内容の表示とバックアップからの復元は利用できます。

インターネット / ネットワーク状態の確認

広告の配信に必要です。登録した内容の送信には使用しません。

広告ID

AdMob が広告の配信に使用します。

その他

上記以外の権限は、広告およびカメラ機能のために、アプリが利用しているライブラリが必要とするものです。開発者が独自に宣言している権限はカメラのみです。

第三者への提供

利用者が登録した内容を第三者へ提供することはありません。そもそも端末の外へ送信していないため、提供の対象となる情報が存在しません。

広告の配信にあたって Google が情報を収集することについては、上記「広告について」をご覧ください。

データの削除

登録した内容は、アプリ内で個別に削除できます。アプリをアンインストールした場合、端末内に保存された内容はすべて削除されます。

書き出し済みのバックアップファイルは、利用者が指定した場所に残ります。不要になった場合は利用者ご自身で削除してください。

お子様のプライバシー

本アプリは13歳以上の方を対象としており、お子様を主な対象としたアプリではありません。広告配信においても「子ども向け」としての設定は行っていません。

本ポリシーの変更

本ポリシーの内容を変更する場合は、このページに掲載します。
